\section{Introduction}

Artificial intelligence in the form of large language models have been growing swiftly in popularity over the last couple of years since 2020. Because of this surge of users who may value experience over technical prowess, it is becoming increasingly important that LLM companies not only have an excellent model for users to interact with, but to also ensure that this interaction is a smooth and excellent experience.

Such a website would have to expect users of all sorts of backgrounds, including:
\begin{itemize}[noitemsep]
    \item Curious grandparents
    \item Lazy students
    \item Professional engineers
    \item People looking for idle conversation
\end{itemize}

Since this wide range of users will have a wide range of use-cases, it becomes imperative that the website is able to support a bevy of features to cater to each user's level of technical expertise. 

The following tests and their metrics aim at exposing how two separate AI LLM companies implement all the features required for such an audience. These two companies shall be: \textbf{OpenAI} and \textbf{Anthropic}.

\section{Methodology}

\subsection{Test Environment and Equipment}
Testing was conducted in a casual home workspace. The usability test environment was configured as follows:
\begin{itemize}[noitemsep]
    \item \textbf{Device:} ASUS TUFF Dash 15 laptop
    \item \textbf{Operating System:} Windows 11
    \item \textbf{Browser:} Opera (latest version)
\end{itemize}

\subsection{Tasks}
Participants must perform the following tasks for both the OpenAI ChatGPT webpage and the Anthropic Claude website. 
\begin{enumerate}[noitemsep]
    \item \textbf{Find} the explanation of what AI is.
    \item \textbf{Find} the chat interface.
    \item \textbf{Create} an account.
    \item \textbf{Locate} the tools provided to the user.
    \item \textbf{Locate} the model modes provided to the user.
    \item \textbf{Locate} the available models.
    \item \textbf{Find} the settings.
    \item \textbf{Find} the memory.
    \item \textbf{Find} the pricing.
    \item \textbf{Use} the project interface.
\end{enumerate}

\subsection{Evaluating Criteria}
Each execution of a task will be evaluated on criteria statements mapping to the five components of usability. The metric queries correspond to the participant's experience.

\subsubsection{Test Metrics}
\begin{itemize}[noitemsep]
    \item \textbf{Effective:} "The task was able to be completed fully."
    \item \textbf{Efficient:} "The task was completed in a timely manner with minimal frustrating interactions."
    \item \textbf{Engaging:} "The website interface feels satisfying and easy to use."
    \item \textbf{Error Tolerant:} "Errors were easy to identify, recover from, or correct."
    \item \textbf{Easy to Learn:} "The task flow is easily explained and highly intuitive."
\end{itemize}
